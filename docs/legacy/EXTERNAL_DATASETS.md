# Внешние данные для редких классов

Цель — добавить независимые видео для `ampulla_of_vater`, `blood_hematin` и `polyp`.
Кадры из того же видео не считаются новыми данными, даже если опубликованы в другом архиве.

## Основной выбор: Galar

[Galar](https://www.nature.com/articles/s41597-025-05112-7) — независимый от
Kvasir-Capsule набор капсульной эндоскопии: 80 исследований, 3 513 539 покадрово
размеченных изображений, два медицинских центра и несколько моделей капсул. Данные и
метаданные опубликованы на [Figshare](https://plus.figshare.com/articles/dataset/Galar_-_a_large_multi-label_video_capsule_endoscopy_dataset/25304616),
а пример обработки — в [официальном репозитории](https://github.com/EKFZ-AI-Endoscopy/GalarCapsuleML).

Соответствие меток:

| Galar | Этот проект | Правило |
|---|---|---|
| `papilla of Vater` | `ampulla_of_vater` | Перед импортом визуально проверить несколько кадров |
| `hematin` | `blood_hematin` | Прямое соответствие |
| `polyp` | `polyp` | Прямое соответствие |

Полный архив занимает около 562 ГБ. Сначала следует получить `Labels` и `metadata`,
посчитать положительные кадры и уникальные исследования по трём меткам, а затем загружать
только нужные наборы кадров. Для честной проверки у класса должно быть хотя бы два независимых
исследования; одно или несколько целых исследований нужно оставить только для validation.

Galar имеет multi-label разметку. Метки качества изображения и отдела ЖКТ не конфликтуют с
нашими классами и могут быть проигнорированы. Если на кадре одновременно стоят две
патологические метки из целевой таксономии, такой кадр нужно исключить из текущей single-label
задачи либо позднее перейти на multi-label модель.

## Локальная копия

Доступная копия Galar находится в `D:\Dataset_galar` и уже содержит PNG-кадры вида
`<study_id>/frame_XXXXXX.PNG`, поэтому `ffmpeg` для неё не нужен. Исследования 41-60 отсутствуют:
два архива источника не удалось скачать. Среди 49 исследований целевого манифеста доступны 40;
пропущены 43, 44, 47, 53, 54, 56, 57, 59 и 60.

Строгий импорт доступной части даёт 37 кадров `ampulla_of_vater`, 18 917 кадров
`blood_hematin` и 5 407 кадров `polyp`. Импорт выполняется без extraction-cap; ограничение 500
кадров применяется позднее только к обучающим `(video_id, label)` группам.

## Дополнительные источники для polyp

### Capsule Vision 2024

[Capsule Vision 2024](https://figshare.com/articles/dataset/Training_and_Validation_Dataset_of_Capsule_Vision_2024_Challenge/26403469)
объединяет SEE-AI, KID, Kvasir-Capsule и AIIMS. В официальной
[таблице происхождения](https://github.com/palaxydf/Capsule-Vision-2024-Challenge)
указано 1 558 кадров `polyp` из SEE-AI и 49 из KID. Ещё 55 кадров пришли из Kvasir — это
имеющиеся у нас кадры, их добавлять нельзя. При импорте обязательно фильтровать поле источника.

Метка `bleeding` здесь объединённая и не равна `blood_hematin`; использовать её как hematin
без повторной медицинской разметки нельзя.

### SEE-AI и KID

- [SEE-AI](https://pmc.ncbi.nlm.nih.gov/articles/PMC10288072/) содержит 18 481 изображение
  из 523 исследований PillCam SB3 с метками `polyp-like` и `bleeding`.
- [KID/KID2](https://mdss.uth.gr/datasets/endoscopy/kid/) использует капсулы MiroCam и
  содержит `polypoid lesions` и общую метку кровотечения.

Эти источники полезны для `polyp` и междоменного переноса, но не дают надёжной отдельной
метки `blood_hematin`. Если уже используется Capsule Vision 2024, нельзя повторно добавлять
те же SEE-AI/KID кадры без проверки дубликатов.

## Правила импорта

1. Сохранить колонки `source_dataset`, исходный `study_id`/`video_id` и номер кадра.
2. Добавить префикс к идентификатору, например `galar_12`, чтобы ID разных наборов не совпали.
3. Делить train/validation только по целым исследованиям, а не по изображениям.
4. Проредить соседние кадры и ограничить длинные эпизоды, не заменяя разнообразие тысячами
   почти одинаковых изображений.
5. Не считать тест честным, пока в validation нет положительного видео, отсутствующего в train.
6. Перед обучением сформировать таблицу: кадры, события и уникальные видео по каждому классу.

Обычные колоноскопические наборы Kvasir-SEG, HyperKvasir и CVC можно использовать для
предобучения признаков полипа, но не как основную validation капсульной модели из-за сильного
различия камер и изображения.
