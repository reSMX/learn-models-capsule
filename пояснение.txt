# Проект: AI-ассистент для капсульной эндоскопии ЖКТ

## Основная идея

Разработка AI-системы, которая анализирует **полную видеозапись капсульной эндоскопии всего желудочно-кишечного тракта** и помогает врачу находить патологические изменения.

ИИ **не ставит диагноз** и **не заменяет врача**.

Его задача:

* автоматически анализировать видеозапись;
* находить подозрительные участки;
* локализовать их;
* предполагать возможный тип патологии;
* формировать удобный отчет;
* помогать врачу сократить время просмотра исследования.

Врач принимает окончательное решение.

---

# Концепция работы

```text
Капсула
      ↓
Видео исследования
      ↓
AI-анализ
      ↓
Поиск подозрительных событий
      ↓
Отчет
      ↓
Проверка врачом
      ↓
Подтвержденные данные
      ↓
Новый датасет
      ↓
Оффлайн переобучение модели
```

Важно:

**никакого online learning.**

Все подтверждения врача лишь пополняют датасет.

Новые версии модели обучаются отдельно после накопления данных.

---

# Что должна делать модель

## 1. Обнаружение патологий

Выделять подозрительные области.

Например:

* полип
* эрозия
* язва
* кровотечение
* опухоль
* воспаление
* метаплазия
* дисплазия
* сосудистые изменения

---

## 2. Локализация

Определять участок ЖКТ.

Например:

* пищевод
* желудок
* двенадцатиперстная кишка
* тонкий кишечник
* толстый кишечник

---

## 3. Анализ последовательности

Главная задача —

не классификация отдельных кадров,

а анализ длинного видеопотока.

Модель должна понимать контекст соседних кадров.

---

## 4. Формирование событий

Не выдавать тысячи кадров.

Вместо этого объединять их в одно событие.

Например:

```
02:17:31–02:17:39

Предположительно:

• эрозия

Confidence: 0.91
```

---

## 5. Формирование отчета

После анализа врач получает:

```
Исследование

Пищевод
✓ без особенностей

Желудок
⚠ подозрительный участок

Тонкий кишечник
⚠ кровотечение

Толстый кишечник
✓ без особенностей
```

Плюс:

* timestamps
* кадры
* вероятность
* комментарии модели

# Основные направления модели

## Visual Encoder

Извлечение признаков изображения.

Возможные варианты:

* ConvNeXt
* ViT
* DINOv2
* BiomedCLIP

---

## Temporal Model

Анализ последовательности кадров.

Возможные варианты:

* Transformer
* Video Transformer
* Mamba
* Temporal CNN

---

## Event Detection

Объединение кадров в события.

Например:

```
300 кадров

↓

1 подозрительное событие
```

# Основные датасеты

## 1. GastroHUN

Лучший открытый датасет именно для гастроскопии.

Содержит:

* 387 пациентов
* ~237 видео
* 8834 изображения
* 4729 видеопоследовательностей
* диагнозы
* анатомические области
* гистологию
* OLGA
* H. pylori

Используется для:

* anatomical localization
* temporal classification

---

## 2. HyperKvasir

Крупный GI dataset.

Содержит:

* 110079 изображений
* 373 видео
* ~1 млн кадров

Подходит для:

* pretraining
* feature learning

Минус:

смешаны верхний и нижний ЖКТ.

---

## 3. Kvasir-Capsule

Главный датасет для капсульной эндоскопии.

Содержит:

* 117 видео
* 4.7 млн кадров
* 47238 размеченных кадров
* 14 классов патологий

Очень важен для проекта.

---

## 4. GIM-ENDO

Небольшой специализированный датасет.

Используется для:

* intestinal metaplasia

# Чем отличается проект

Не просто:

> найти полип.

А:

создать полноценного AI-ассистента.

Функции:

* анализ полного исследования;
* понимание отдела ЖКТ;
* поиск патологий;
* объединение кадров в события;
* помощь врачу;
* автоматическое создание отчета;
* накопление новых размеченных данных.

# Главная идея проекта

Это **не система автоматической диагностики**, а **интеллектуальный ассистент врача**, который анализирует длинные записи капсульной эндоскопии всего ЖКТ, помогает находить потенциальные патологии, структурирует результаты исследования и со временем может улучшаться за счет накопления верифицированных врачами данных через контролируемое офлайн-переобучение.
